# Laravel 13 sports app foundation

Framework setup only; sports features and custom authentication are not implemented.
Read [AGENTS.md](../AGENTS.md), the [product plan](../docs/PRODUCT_PLAN.md), and the [setup guide](../docs/SETUP.md).
Use PHP 8.5, Composer, and Node/npm. Start with php artisan serve --host=127.0.0.1 --port=8000.
SQLite is disposable local setup data. Serve only public/, never the repository root.
