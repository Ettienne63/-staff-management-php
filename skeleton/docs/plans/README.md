# Task plans

`/ticket` writes one readable plan per task here, named `<task-key>-<slug>.md`: scope, decisions, steps and risks, written for a person rather than an agent.

**Plans stay on the machine that wrote them.** `.gitignore` ignores everything in this folder except this README, on every clone. Don't commit or force-add a plan. Anything in one that the project should keep goes into `docs/PRODUCT_PLAN.md`, `docs/ROADMAP.md`, `docs/decisions.md` or the PR description.
